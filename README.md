# Empowering Education - Campus Book Exchange

A platform designed for students to easily exchange, buy, sell, rent, and donate books on campus. 

## Features
- **Buy Books**: Browse and purchase books from other students.
- **Sell Books**: List your old books for sale.
- **Rent Books**: Find affordable textbook rentals for the semester.
- **Donate Books**: Give away books you no longer need to help others.

## Technologies Used
- HTML5
- CSS3 (Bootstrap 5)
- JavaScript

## Setup
1. Clone the repository.
2. Open `index.html` in your web browser.
